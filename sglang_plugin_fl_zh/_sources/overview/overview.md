# sglang-plugin-FL 概述

sglang-plugin-FL 是 [SGLang](https://github.com/sgl-project/sglang) 的树外（OOT）插件，构建于 FlagOS 的统一多芯片后端之上——包括统一算子库 [FlagGems](https://github.com/flagos-ai/FlagGems) 和统一通信库 [FlagCX](https://github.com/flagos-ai/FlagCX)。它将 SGLang 的推理能力扩展到多种硬件平台。无需更改 SGLang 的原始接口或使用方式，同一命令即可在不同芯片上运行模型推理。
