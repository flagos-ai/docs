# FlagScale v1.0.0 Release Notes

## Highlights

- **Unified FlagScale CLI** — a single entry point for all operations, with unified multi-chip training support across NVIDIA GPU, Ascend, and MUSA.
- **VeRL-FL & expanded model support** — replaced third-party verl with [VeRL-FL](https://github.com/flagos-ai/verl-FL) and expanded model support to include Qwen3-VL, Qwen2.5-VL, GR00T N1.5, and DeepSeek Engram.
