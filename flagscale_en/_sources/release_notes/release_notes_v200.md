# FlagScale v2.0.0 Release Notes

## Highlights

- **DeepSeek V4 & Qwen3.5 support** — DeepSeek V4 training support with Engram optimization, and the new Qwen35 model.
- **Megatron-LM Core 0.17.0 upgrade** — FlagScale Train synchronized with upstream Megatron-LM Core 0.17.0, with a new `--mg-fl-prefer` argument for Megatron-LM-FL vendor selection.
- **FSDP2 checkpoint resume** — training supports resuming from FSDP2 checkpoints.
- **Robotics** — the `flagscale eval robo` CLI; qwen_gr00t now supports the Ascend and MUSA platforms for both training and inference.
