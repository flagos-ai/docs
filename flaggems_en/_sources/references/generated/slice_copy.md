# slice_copy

**Kind:** Tensor | **Stage:** alpha | **Since:** 5.5

## Description

Performs the same operation as `torch.slice`, but all output tensors are freshly
created instead of aliasing the input. Returns a new tensor containing the
selected slice of `self` along the given dimension.
