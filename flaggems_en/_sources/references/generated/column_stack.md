# column_stack

**Kind:** Tensor | **Stage:** alpha | **Since:** 5.4

## Description

Creates a new tensor by horizontally stacking the tensors in tensors. Equivalent to
torch.hstack after 0-D and 1-D tensors have been reshaped into (numel, 1) columns.
