# masked_softmax_backward

**Kind:** NeuralNetwork | **Stage:** alpha | **Since:** 5.5

## Description

Computes the input gradient of a masked softmax: masked positions are
zeroed and the remaining positions follow the standard softmax backward
formula output * (grad_output - sum(output * grad_output over dim)).
