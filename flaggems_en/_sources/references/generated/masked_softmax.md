# masked_softmax

**Kind:** NeuralNetwork | **Stage:** alpha | **Since:** 5.5

## Description

Apply a softmax over `dim` while excluding positions where the boolean
mask is True. mask_type selects how the mask broadcasts: 2 for an
elementwise mask, 1 for a (B, L) attention padding mask, and 0 for an
(L, L) source mask.
