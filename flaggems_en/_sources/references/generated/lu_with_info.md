# lu_with_info

**Kind:** LinearAlg | **Stage:** alpha | **Since:** 5.4

## Description

Computes a compact LU factorization with partial pivoting of a matrix,
returning the packed LU matrix, the 1-indexed pivots and an info tensor
that reports the first singular diagonal of U (0 on success). This is the
deprecated `torch._lu_with_info` interface mirrored on `linalg.lu_factor_ex`.
