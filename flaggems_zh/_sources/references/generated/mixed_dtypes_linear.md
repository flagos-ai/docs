# mixed_dtypes_linear

**Kind:** BLAS | **Stage:** alpha | **Since:** 5.5

## Description

Weight-only quantized matrix multiplication (CUTLASS fpA_intB semantics).
Computes out = activation(input @ dequant(weight) + bias) where weight is uint8
(int8 mode: (u-128)*scale or packed int4 mode: (u-8)*scale). Bias and activation
are optional.
