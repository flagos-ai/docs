# hash_tensor

**Kind:** Reduction | **Stage:** alpha | **Since:** 5.4

## Description

Reduces the input tensor by XOR-ing the raw 64-bit representations of its elements over the given dims (an empty dim list reduces over all elements).
Floating types are widened to float64 and bit-cast to uint64; integer and bool types are extended to int64 and bit-cast to uint64. The output dtype is always uint64 and mode must be 0.
