# cosine_similarity

**Kind:** Reduction | **Stage:** alpha | **Since:** 5.5

## Description

Computes the cosine similarity between x1 and x2 along dim, broadcasting the
inputs to a common shape first. Returns <x1, x2> / (max(||x1||_2, eps) *
max(||x2||_2, eps)) reduced over dim, with eps guarding against zero norms.
