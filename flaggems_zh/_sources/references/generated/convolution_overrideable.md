# convolution_overrideable

**Kind:** Convolution | **Stage:** alpha | **Since:** 5.4

## Description

Generic overrideable convolution dispatch. Infers the spatial rank from
the weight tensor and routes to the FlagGems Triton convolution kernels
(forward `conv2d` im2col kernel and transposed conv variants), supporting
stride, padding, dilation, transposed, output_padding and groups.
