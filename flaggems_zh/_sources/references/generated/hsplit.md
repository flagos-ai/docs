# hsplit

**Kind:** Tensor | **Stage:** alpha | **Since:** 5.4

## Description

Split a tensor into multiple sub-tensors horizontally (column-wise).
Equivalent to tensor_split with dim=1 for 2D+ tensors, or dim=0 for 1D tensors.
