# smm

**Kind:** Math | **Stage:** alpha | **Since:** 5.4

## Description

Performs a matrix multiplication of the sparse (COO) matrix `self` with the
dense matrix `mat` using a fused Triton kernel. The sparse operand is
materialized to dense, the product is computed with `tl.dot`, and the COO
output (indices + values) is written directly to match `torch.smm`
semantics: every row that appears in the sparse input contributes all
output columns.
