# isreal

**Kind:** Math | **Stage:** alpha | **Since:** 5.5

## Description

Tests whether each element is real, i.e. whether its imaginary part is
zero, and returns a bool tensor. Real-valued dtypes are always True; for
complex dtypes the imaginary component is compared against an exact zero
(a negative zero counts as zero).
