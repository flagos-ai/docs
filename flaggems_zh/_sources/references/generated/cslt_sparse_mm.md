**Kind:** Tensor | **Stage:** alpha | **Since:** 5.5

## Description

Triton implementation of aten._cslt_sparse_mm; decodes the cuSPARSELt 2:4 structured-sparse compressed blob back to dense and runs a tiled dense matmul, supporting alpha, bias, and transpose_result. The compressed layout is architecture specific, so this decoder targets the Hopper swizzle and is only registered on compute capability 9.x; other architectures keep using the native cuSPARSELt op.
