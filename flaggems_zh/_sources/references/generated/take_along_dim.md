# take_along_dim

**Kind:** Tensor | **Stage:** alpha | **Since:** 5.5

## Description

Selects values from `input` at the 1-dimensional `indices` along the
given `dim`. Reduces to a broadcasted gather; if `dim` is None the input
is treated as flattened to 1-D.
