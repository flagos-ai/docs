# Certification Maintenance

- Validity period: 12 months; recertification is required at expiration.

- Changes triggering retesting: major driver upgrades, Triton backend refactoring, or major PyTorch upgrades.

- Certification revocation: a CI pass rate below 80% for three consecutive months, or an unresolved critical security vulnerability.

- Waiver management: each waiver must state the technical reason, remediation plan, and expected remediation date; the maximum waiver period is six months.
