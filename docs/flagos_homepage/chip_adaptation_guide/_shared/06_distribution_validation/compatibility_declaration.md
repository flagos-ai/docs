# Compatibility Declaration

|**Declaration level**|**Meaning**|**Condition**|
|---|---|---|
|Platinum Partner|The chip is fully supported in the distribution.|Passes Level 1 + Level 2 + Level 3 validation and is an advanced partner.|
|Certified|The chip is certified to run normally in the distribution.|Passes Level 1 + Level 2 validation.|
|Compatible|The chip is verified as compatible in the distribution.|Passes at least Level 1 validation.|
|Community Support|Community-driven support without official distribution validation.|Only FlagOS CTS has passed.|
