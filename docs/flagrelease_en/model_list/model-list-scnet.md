# Models on SCNet

FlagOS download entry on the SCNet (Supercomputing Internet) AI community:

<https://www.scnet.cn/ui/aihub/models?authenticated=FlagOS>

Opening the link takes you to the model library archived under FlagOS. It currently hosts 9 FlagOS-adapted images, including Qwen3.8-2.4T, Qwen3.6-35B, Qwen3.5-35B, MiniMax M2.7, and MiniCPM5. Sign in to download or deploy them.

The FlagOS software stack itself (installation packages and application images) is available on the official resource download page: <https://flagos.io/resourcedownload>.
